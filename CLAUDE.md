# fosrpg-pages — заметки для Claude Code

Репозиторий деплоя: GitHub Pages раздаёт игру FosRPG из папки `docs`.

- `docs/` — артефакт сборки клиента из репозитория `fosemberg/fosrpg`. Ничего в нём не
  править вручную: следующий деплой заменит папку целиком (сохраняется только `CNAME`).
- Обновление: в чекауте `fosrpg` выполнить `bun run deploy:pages` (скрипт
  `scripts/deploy-pages.sh` собирает клиент с относительным base, заменяет `docs/` и кладёт
  `.nojekyll`), затем закоммитить `docs/` здесь и запушить в ту же ветку
  (`bun run deploy:pages --push` делает это сам).
- Любое изменение в `fosrpg` должно сопровождаться новым деплоем сюда — см. `CLAUDE.md`
  в `fosrpg`.
